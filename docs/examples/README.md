# Gold-standard examples

Real outputs that represent Zevero at its best: the discovery brief before a deal we won, the follow-up that got a reply, the proposal the CFO signed. They set the bar for skills and evals.

- **One folder per skill:** `docs/examples/<skill>/<short-name>.md`.
- **Anonymise first.** Replace customer, contact and price details with `[Prospect]`, `[Name]` and `[£X]`.
- **Add a line at the top** saying why it's good: what it did that won the deal.
- **Ways to add one:**
  - Say "that was great" after a skill output; `skill-feedback` offers to file it.
  - Or open a PR.

Skill owners pull patterns from these into the skill text and eval criteria each quarter.
